# 日記画像の猫キャラクターガイド

日記画像で名前のある猫は、下記の3匹だけを公式キャラクターとして扱います。新しい画像を作るときは、必ず参照画像を同時に渡し、毛色だけでなく毛の長さ・目・首輪・チャームまで一致させます。2026年8月13日以降の全面改稿版では猫を画面の主役にし、なおくんは場面の端にいる小さな「顔のないうんち」として統一します。

## ゲスト猫のルール

- トラちゃん、キキ、フワ以外の猫を登場させてもよい。
- ゲスト猫には本文中で固有名を付けず、「ゲスト猫」として扱う。
- 公式3匹と誤認しないよう、柄・毛色・体格・小物のいずれかを明確に変える。
- 三毛、サバトラ、ハチワレ、ポイントカラーなどを優先し、公式3匹のミント首輪、蝶ネクタイ、星・三日月チャームは流用しない。
- 同じ毛色のゲストを出す場合は、赤いバンダナなど公式アクセサリーと重ならない目印を付ける。

## 画像生成・編集の手順

1. 本文の `catIds` と画像内の配役を照合する。
2. トラちゃん、キキ、フワの参照画像をこの順で渡し、本文に登場する猫だけを新しい場面へ描く。
3. 全面改稿版は正方形の全面イラストにし、古い罫線ノート、青い枠、空白の題名欄を引き継がない。
4. 本文に名前がある猫は、毛色・毛の長さ・目・アクセサリーの4点をすべて指定する。
5. ゲスト猫は「残す」「追加する」「公式3匹と異なる目印」をプロンプトへ明記する。
6. なおくんは茶色いうんちそのものとして描き、目、口、鼻、頭、髪、人間の顔、人間の体、手足を付けない。衣装回でも小物だけを添え、顔は作らない。
7. 1200 x 1200 以上の正方形WEBPとして保存し、一覧表示でも登場猫を識別できるか確認する。

## レビュー項目

- トラちゃんが三毛、灰色、無地のオレンジになっていない。
- キキが灰色や長毛になっておらず、金色の目と三日月チャームで判別できる。
- フワが短毛になっておらず、白い長毛と星チャームで判別できる。
- 眠っている、後ろ向き、衣装を着ている場面でも、縞・毛量・首輪など最低2つの特徴が見える。
- 写真、鏡、絵の中に同じ猫が再登場する場合、その中の姿も本体と一致する。
- ゲスト猫が公式3匹と同じ識別アクセサリーを付けていない。
- 本文で名前を呼ぶ猫と画像内の役割が一致する。
- 猫が主役として最も大きく描かれ、なおくんが中央の主人公になっていない。
- なおくんに顔や人間の体がなく、完全なうんちとして描かれている。
- 画像内に文字、吹き出し、透かし、罫線ノート、青い飾り枠がない。
