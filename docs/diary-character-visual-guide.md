# 日記画像の猫キャラクターガイド

日記画像で名前のある猫は、下記の3匹だけを公式キャラクターとして扱います。新しい画像を作るときは、必ず参照画像を同時に渡し、毛色だけでなく毛の長さ・目・首輪・チャームまで一致させます。

## 公式キャラクター

| 名前 | 参照画像 | 固定する見た目 | 識別用アクセサリー |
| --- | --- | --- | --- |
| トラちゃん | `/content/collections/cats/maron.webp` | オレンジ色の茶トラ。額・頬・脚・しっぽに濃いオレンジの縞。口元・胸・足先はクリーム色。ピンクの鼻 | ミント色の蝶ネクタイ首輪 |
| キキ | `/content/collections/cats/kuro.webp` | 短毛の真っ黒な猫。大きな金色から琥珀色の目。ピンクの鼻 | ミント色の首輪と金色の三日月チャーム |
| フワ | `/content/collections/cats/yuki.webp` | 純白の長毛猫。頬・胸元・しっぽは雲のようにふわふわ。ミントグリーンの目。ピンクの鼻 | ミント色の首輪と金色の星チャーム |

## ゲスト猫のルール

- トラちゃん、キキ、フワ以外の猫を登場させてもよい。
- ゲスト猫には本文中で固有名を付けず、「ゲスト猫」として扱う。
- 公式3匹と誤認しないよう、柄・毛色・体格・小物のいずれかを明確に変える。
- 三毛、サバトラ、ハチワレ、ポイントカラーなどを優先し、公式3匹のミント首輪、蝶ネクタイ、星・三日月チャームは流用しない。
- 同じ毛色のゲストを出す場合は、赤いバンダナなど公式アクセサリーと重ならない目印を付ける。

## 画像生成・編集の手順

1. 本文の `catIds` と画像内の配役を照合する。
2. 編集対象の日記画像を1枚目に、トラちゃん、キキ、フワの参照画像をこの順で続けて渡す。
3. 構図、人物、なおくん、背景、小道具、紙の質感、色鉛筆風の線は維持し、猫の外見だけを修正する。
4. 本文に名前がある猫は、毛色・毛の長さ・目・アクセサリーの4点をすべて指定する。
5. ゲスト猫は「残す」「追加する」「公式3匹と異なる目印」をプロンプトへ明記する。
6. 1200 x 1200 以上の正方形WEBPとして保存し、一覧表示でも3匹を識別できるか確認する。

## レビュー項目

- トラちゃんが三毛、灰色、無地のオレンジになっていない。
- キキが灰色や長毛になっておらず、金色の目と三日月チャームで判別できる。
- フワが短毛になっておらず、白い長毛と星チャームで判別できる。
- 眠っている、後ろ向き、衣装を着ている場面でも、縞・毛量・首輪など最低2つの特徴が見える。
- 写真、鏡、絵の中に同じ猫が再登場する場合、その中の姿も本体と一致する。
- ゲスト猫が公式3匹と同じ識別アクセサリーを付けていない。
- 本文で名前を呼ぶ猫と画像内の役割が一致する。
